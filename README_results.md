## Relationship to this repository

The GitHub repository contains the experimental code and supporting documentation. This external folder contains the larger result artifacts, which may include experiment outputs, figures, tables, serialized models, and intermediate files. The exact contents should be confirmed against the hosted directory.

For reproducibility, consult the repository's main `README.md`, experimental index, and reproducibility documentation. Results should be interpreted using the evaluation protocol associated with each experiment; outputs from different validation settings are not necessarily directly comparable.
