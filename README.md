## Overview

This repository preserves the collected experimental materials associated with the study, including leakage-aware preprocessing, dependency-constrained views, multi-view learning, fusion and stacking, and temporal/cross-dataset evaluations using NHANES and HRS.

The original `Collected` folder structure is retained. Consult `EXPERIMENT_INDEX.md` and `file_manifest.csv` where available to locate scripts and inputs. The presence of a file does not establish independent reproduction of reported metrics.
